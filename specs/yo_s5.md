# yo-s5 产品需求规格

> 只写代码说不出来的东西：定位、设计取舍、做不到的。命令行为看 `yo-s5 --help` 与 `src/s5/`。

---

## 1. 产品定位

**yo-s5 是一个一键部署 SOCKS5 + HTTP 同端口代理的工具。**

目标用户是需要在 Linux 服务器上快速搭建 SOCKS5 代理的开发者。传统方式需要手动安装软件、配置认证、开放端口、测试连通性，yo-s5 把这些全部自动化。

核心理念：**一条命令，代理就能用。**

---

## 2. 设计决策

| 决策 | 理由 |
|------|------|
| 基于 Docker + GOST v3 | 无需编译安装，GOST 是成熟的代理工具，Docker 确保环境隔离；锁定 `gogost/gost:3` 以支持 `auto://` |
| `auto://` 同端口多路复用 | 一个端口同时服务 SOCKS5（浏览器/通用客户端）与 HTTP CONNECT（部分 SDK 只支持 HTTP 代理），零额外端口、共用同一套账号密码 |
| 自动安装 Docker | 降低使用门槛，用户不需要预先准备环境 |
| 随机密码 + 随机端口 | 自动模式追求零配置，安全性由随机性保证 |
| JSON 格式输出配置 | 方便程序化使用，可直接粘贴到客户端配置 |
| 连通性测试 | 部署完自动验证，确保代理确实可用 |
| 拒绝 WSL 环境 | WSL 网络栈不完整，SOCKS5 代理在 WSL 中无法正常对外服务 |

---

## 3. 当前已知限制

- **仅 Linux 支持：** 依赖 Docker 和 Linux 网络栈
- **WSL 不可用：** 主动检测并拒绝在 WSL 中运行
- **固定用户名：** 认证用户名固定为 `admin`，仅密码可自定义
- **单容器模式：** 每次运行只部署一个代理实例
